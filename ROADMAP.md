# Roadmap

ReadLaterCleaner starts as a compact Manifest V3 MVP. The next releases focus
on making review sessions faster and import/export safer.

## v0.1 - Public MVP

- Save current tab and all current-window tabs
- Local link library in `chrome.storage.local`
- Search and status filters
- Review mode for old unread links
- Duplicate detection and merge/delete flow
- Markdown export and JSON backup import/export

## v0.2 - Editing Flow

- Inline title, note, and tag editing
- Bulk status updates for selected links
- Better duplicate merge preview
- Keyboard shortcuts for review actions

## v0.3 - Safer Backups

- Import preview before replacing data
- Merge/replace modes for JSON backups
- Backup validation report
- Export selected links only

## v0.4 - Review Quality

- Custom review batch size
- Snooze and keep-for-later actions
- Age and domain filters in review mode
- Better empty states for new users

## Later

- Firefox compatibility review
- Optional CSV export
- Optional reading-time metadata
- Local-only folder/group organization
