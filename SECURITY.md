# Security Policy

## Supported version

Security fixes target the latest version on `main` while the project is in MVP
development.

## Reporting a vulnerability

Please do not publish sensitive security or privacy reports in public issues.
Use GitHub private vulnerability reporting when available, or contact the
maintainer through the public GitHub profile.

Useful reports include:

- Steps to reproduce
- Browser and operating system
- The affected extension version
- Potential impact
- Suggested fix, if known

ReadLaterCleaner should never transmit saved links to a remote service.
